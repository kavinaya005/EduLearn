# EduLearn — Frontend Login Demo

Open `index.html` in your browser to view the simple login page.

Quick steps:

- Double-click `frontend/index.html` or open it from your browser's File → Open.
- The page uses Tailwind via the CDN; no build step required.

Notes:
- This is front-end only (no server). The form uses JavaScript for validation and a demo "remember me" using `localStorage`.
